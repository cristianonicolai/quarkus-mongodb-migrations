= Quarkus MongoDB Migrations

include::./includes/attributes.adoc[]

Write MongoDB migrations as Java code, blocking or reactive, and run them once, in order, with a lock so only one instance runs them. Migrations can run at startup or as a Kubernetes init job.

== Installation

To use this extension, add the `io.quarkiverse.mongodb-migrations:quarkus-mongodb-migrations` dependency to your build file.

With Maven, add the following to your `pom.xml`:

[source,xml,subs=attributes+]
----
<dependency>
    <groupId>io.quarkiverse.mongodb-migrations</groupId>
    <artifactId>quarkus-mongodb-migrations</artifactId>
    <version>{project-version}</version>
</dependency>
----

With Gradle, add the following to your `build.gradle`:

[source,gradle,subs=attributes+]
----
implementation("io.quarkiverse.mongodb-migrations:quarkus-mongodb-migrations:{project-version}")
----

== Usage

Annotate a class with `@Migration` and implement `MongoMigration` (or `ReactiveMongoMigration`):

[source,java]
----
@Migration(id = "create-users-email-index", order = 1)
public class CreateUsersEmailIndex implements MongoMigration {

    @Override
    public void apply(MigrationContext context) {
        context.createIndex("users", "email_idx", ascending("email"));
    }
}
----

Then run pending migrations at startup:

[source,properties]
----
quarkus.mongodb-migrations.migrate-at-start=true
----

See the project README for reactive migrations, Kubernetes jobs and the helper functions.
